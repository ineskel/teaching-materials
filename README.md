# Teaching Materials

Practical teaching materials and Jupyter notebooks developed for introducing beginner-level concepts across different contexts, including artificial intelligence, data analysis, and computational neuroscience.

## Contents

| Notebook | Description |
|---|---|
| [Challenge – Diabetes EDA](https://github.com/ineskel/teaching-materials/blob/main/Challenge_%20Diabetes%20EDA.ipynb) | Hands-on EDA challenge using a diabetes dataset. Designed to help beginners practise data exploration, visualisation, and interpretation. |
| [EDA Walkthrough – Penguins](https://github.com/ineskel/teaching-materials/blob/main/EDA_Walkthrough_Penguins.ipynb) | Guided exploratory data analysis using the Palmer Penguins dataset, introducing common EDA techniques through a practical example. |
| [Fundamentals of AI](https://github.com/ineskel/teaching-materials/blob/main/Fundamentals%20of%20AI%20Notebook.ipynb) | Notebook accompanying introductory AI teaching materials, covering foundational concepts through practical exercises. |
| [Extended Linear Algebra Exercises (AiN)](https://github.com/ineskel/teaching-materials/blob/main/%5BAiN%5D_Extended_linear_algebra_exercises.ipynb) | Supplementary linear algebra exercises prepared for the Arabs in Neuroscience educational programme. |

## Purpose

These materials were created to support teaching and learning through practical exercises rather than theory alone. They are intended to make foundational concepts more accessible by connecting them to concrete datasets, coding tasks, and worked examples.

## Usage

The notebooks can be viewed directly on GitHub or downloaded and run locally using Jupyter Notebook or JupyterLab.

Some notebooks may require additional Python libraries. Check their import cells and install any missing dependencies before running them.
